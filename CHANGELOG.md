# История изменений

Версия показана внизу каждой страницы панели и лежит в `app/version.py`.

## 1.10.0 — 2026-10-17
- **Защита SSH на странице сервера.** Новый блок показывает, установлен ли fail2ban, сколько IP сейчас в бане, сколько было неудачных
  входов по SSH за сутки, разрешён ли вход по паролю и root.
- **fail2ban одной кнопкой:** jail `sshd` (по умолчанию 5 неудачных попыток за 10 минут → бан на час, повторным нарушителям срок
  удваивается до недели), файл `/etc/fail2ban/jail.d/solahelm.local`, `backend` выбирается сам (journald или auth.log). IP, с которого
  подключается панель, всегда в `ignoreip` — панель не забанит саму себя; можно добавить свои адреса. Конфиг проверяется `fail2ban-client -t`,
  при ошибке откатывается. Список забаненных IP с кнопкой «Разбанить».
- **Запрет входа по паролю:** `/etc/ssh/sshd_config.d/00-solahelm.conf` (`PasswordAuthentication no`, `PermitRootLogin prohibit-password`).
  Доступно, только если панель уже входит по ключу; можно сразу добавить свой публичный ключ. После изменения панель проверяет новым
  SSH-подключением, что может войти, иначе откатывает настройку через ещё открытое соединение. Обратная кнопка «Разрешить вход по паролю».
- Проверено на Debian 12 (journald) и в контейнере Debian 12 с auth.log.

## 1.9.0 — 2026-10-12
- **Добавлен протокол Naive** (HTTPS/HTTP3, sing-box): седьмой протокол рядом с Hysteria2, VLESS Reality, AnyTLS, Trojan, TUIC и Shadowsocks-2022.
  Использует домен и сертификат TLS-протоколов, порт по умолчанию 6443 (TCP + UDP), ссылка `naive+https://`. В Clash его нет: Clash Meta / mihomo Naive не поддерживает.
  Логин и пароль клиента — имя и пароль профиля.
- Не добавлены Snell, VMess, ShadowTLS (решение: мало пользы как запасные каналы).

## 1.8.1 — 2026-10-12
- **Исправлено: протоколы sing-box не работали на VPS без systemd-resolved** (ошибка «org.freedesktop.resolve1 was not provided», клиент видел EOF).
  Теперь в конфиг sing-box добавляется собственный DNS (1.1.1.1 / 8.8.8.8), `route.default_domain_resolver`. Существующий конфиг дополняется при ближайшей синхронизации
  (если в нём уже есть раздел `dns`, он не трогается).

## 1.8.0 — 2026-10-12
- **Больше протоколов для обхода блокировок:** к Hysteria2, VLESS Reality и AnyTLS добавлены **Trojan**, **TUIC v5** и **Shadowsocks-2022**.
  Включаются по отдельности в блоке «sing-box» на странице сервера, у каждого свой порт; у профиля для каждого протокола есть ссылка, QR, запись в подписке и в Clash.
  Если заблокируют один протокол, клиент переключается на другой.
- TLS-протоколы (AnyTLS, Trojan, TUIC) используют общий домен и сертификат; Shadowsocks-2022 работает без домена (ключ сервера + ключ профиля, создаются автоматически, существующим профилям добавляются при обновлении).
- Профили: пароль должен быть уникальным (Trojan/AnyTLS различают пользователей только по паролю); при сборке конфига дубликаты отфильтровываются.
- Конфиги проверены настоящим `sing-box check` (v1.14.3) для всех протоколов по отдельности и вместе.
- Обновление: `sudo bash deploy/install-linux.sh`, затем на странице сервера «Применить / переустановить» и откройте новые порты.

## 1.7.0 — 2026-10-05
- **Двуязычный интерфейс (русский / английский).** Переключатель RU | EN справа вверху на каждой странице, включая входы в админку
  и в кабинет клиента; выбор запоминается. Язык по умолчанию задаётся `HY_DEFAULT_LANG` (`ru` | `en` | `auto` — по браузеру).
  Переводятся страницы, сообщения, ошибки, журнал установки, подсказки скриптов. Единицы и время (`МБ`/`MB`, `ч`/`h`, «назад»/`ago`) форматируются на нужном языке.
  Словарь: `app/i18n_en.py`, проверка полноты: `python scripts/i18n_extract.py`.
- **Название продукта — SolaHelm** (параметр `HY_BRAND`): шапка, заголовки страниц, подвал. Технические имена (служба `hy2panel`,
  каталог `/opt/hy2panel`) прежние, чтобы обновление не ломало установленную панель.
- **Маскировка адресов.** Установщик при первой установке создаёт случайные префиксы (кабинет клиентов и админка); новый адрес админки:
  `sudo ROTATE_ADMIN_PATH=1 bash deploy/install-linux.sh`. Любой чужой путь отвечает неотличимой от nginx страницей 404.
  Старые префиксы (`HY_LEGACY_BASE`) больше не перенаправляют на админку, адрес админки никому не раскрывается.
- Установщик: сообщения на двух языках, домен сайта берётся из `HY_PUBLIC_URL` / спрашивается (больше не зашит).
- Внутреннее: сообщения установочных скриптов вынесены в `sh_echo()` (переводимы); заголовки скачиваемых YAML на английском.

## 1.6.0 — 2026-10-04
- **Новая схема адресов:** клиенты `https://panel.example.com/hy/` (вход в кабинет, подписки `/hy/sub/<токен>`),
  админка `https://panel.example.com/hy/admin/`. Префиксы задаются `HY_BASE_PATH` (публичный) и `HY_ADMIN_PATH` (подпапка админки).
- **Прежние адреса не ломаются:** в `HY_LEGACY_BASE` указывается старый префикс (например `/hy-admin`). Подписки по старым ссылкам
  продолжают работать, остальные страницы перенаправляются на новые адреса. Публичный адрес в настройках панели
  переносится автоматически.
- Установщик сам переводит старый `.env` на новую схему (с бэкапом `.env.bak-*`) и пересоздаёт конфиг nginx.
  Куки админки ограничены путём `/hy/admin`, на публичные адреса они не отправляются.

## 1.5.0 — 2026-10-01
- **Доступ профилей к серверам.** Новая страница «Доступ»: матрица профили × серверы с мгновенными переключателями
  (и кнопками «все / никто» по строке и колонке); изменения сразу уходят в конфиги серверов.
- У сервера появилась настройка **«Предлагать новым профилям по умолчанию»**: новые профили больше не получают
  все серверы подряд. Для уже добавленных серверов флаг включён (прежнее поведение), для новых по умолчанию выключен.
- На странице сервера: кнопка **«Убрать»** у профиля и блок **«Добавить профили на этот сервер»**.
- На странице сервера показывается **расхождение** конфига Hysteria с панелью (пользователи, добавленные или убранные руками)
  и кнопка «Синхронизировать сейчас». В списке профилей видны имена серверов и пометка «нет серверов».

## 1.4.0 — 2026-09-30
- **Мониторинг:** разовые сбои SSH больше не дают «нет связи». Опрос повторяется сам, при неудаче остаются последние известные данные,
  а статус «нет связи» ставится после N неудач подряд (по умолчанию 3, настраивается в «Настройках»).
  Таймауты SSH увеличены.
- **График доступности** на странице сервера (24 часа / 7 дней / 30 дней): процент доступности, время ответа, список сбоев;
  компактная полоса за 24 часа на карточках «Обзора». История хранится 35 дней.
- **Конфиг sing-box (VLESS / AnyTLS)** можно смотреть и править на странице сервера. Сохранение делает бэкап, проверяет
  `sing-box check` и перезапускает службу; есть откат к последнему бэкапу.
- **QR-коды:** исправлено обрезание длинных ссылок (Hysteria2 с obfs, VLESS). QR масштабируются и сканируются.
- Введённое в формах установки (Hysteria2, sing-box) запоминается и не пропадает после «Назад» из консоли задачи.
