# SolaHelm для начинающих: пошаговая инструкция

> English: [GUIDE.md](GUIDE.md) · Полное описание: [README.ru.md](README.ru.md)

Цель: за один вечер получить свою панель, подключить к ней VPS с VPN и выдать первому клиенту ссылку.
Все примеры ниже условные: **подставьте свои значения** (`myhelm.mooo.com`, `203.0.113.10` и т. д.).

## Что понадобится

| Что | Пример | Зачем |
|---|---|---|
| Компьютер или ВМ с Ubuntu/Debian (или Windows с WSL2), включён systemd | домашний мини-ПК | здесь будет жить панель |
| Доменное имя | `myhelm.mooo.com` | нужно для HTTPS; своего нет — см. шаг 1 |
| VPS с Debian/Ubuntu и доступом по SSH под root | `203.0.113.10` | сам VPN-сервер |
| 30–60 минут | | |

Схема: **вы → панель (nginx + SolaHelm) → по SSH → ваш VPS**. Клиенты подключаются к VPS, а ссылки и подписки берут у панели.

## Шаг 1. Получите домен (если своего нет)

1. Зайдите на <https://freedns.afraid.org/signup/>, зарегистрируйтесь, подтвердите письмо.
2. **Subdomains → Add**: Type `A`, Subdomain `myhelm`, Domain `mooo.com`, Destination — публичный IP машины с панелью
   (узнать: `curl ifconfig.me`). Нажмите Save.
3. Для VPS сделайте вторую запись: Subdomain `vps1`, Destination `203.0.113.10`.
4. Проверка (через 5–10 минут): `nslookup myhelm.mooo.com`. Должен показать ваш IP.

Если панель дома за роутером: пробросьте на роутере TCP-порты **80 и 443** на машину с панелью.
Подробности и вариант с меняющимся IP: раздел «Нет своего домена?» в [README.ru.md](README.ru.md).

## Шаг 2. Поставьте nginx и сертификат

На машине панели (команды выполняются по очереди):

```bash
sudo apt update
sudo apt install -y nginx certbot python3-certbot-nginx git
sudo certbot --nginx -d myhelm.mooo.com
```

Certbot спросит e-mail и согласие с условиями. По окончании откройте `https://myhelm.mooo.com` в браузере:
должна открыться страница nginx без предупреждений о сертификате.

## Шаг 3. Установите SolaHelm

```bash
git clone https://github.com/sola21/solahelm.git
cd solahelm
sudo bash deploy/install-linux.sh
```

Ответы на вопросы установщика:

| Вопрос | Что ввести (пример) |
|---|---|
| Домен сайта | `myhelm.mooo.com` |
| Публичный префикс для клиентов | просто **Enter** (будет случайный) |
| Логин администратора | `admin` |
| Пароль | длинный, уникальный (не такой, как в примерах!) |

В конце установщик напечатает адреса. **Скопируйте адрес админки в надёжное место**: он случайный намеренно и
выглядит примерно так: `https://myhelm.mooo.com/k3x9/a7f2q1/`.

Защитите админку по IP (рекомендуется): откройте `/etc/nginx/snippets/hy2panel-admin-acl.conf`, раскомментируйте
`allow` (впишите свой IP) и `deny all;`, затем:

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## Шаг 4. Войдите в админку

Откройте адрес админки из шага 3, введите логин и пароль. Язык переключается кнопкой **RU | EN** справа вверху.

Если что-то не работает: `journalctl -u hy2panel -f` покажет журнал панели.

## Шаг 5. Добавьте VPS

1. **Серверы → Добавить VPS**: адрес `203.0.113.10`, порт SSH `22`, пользователь `root`.
2. Доступ по SSH: в **Настройки → «SSH-ключ панели»** скопируйте публичный ключ и добавьте его на VPS в
   `~/.ssh/authorized_keys`. Или выберите «Пароль» один раз и нажмите «Установить ключ панели».
3. Нажмите **Проверить**: должно появиться состояние сервера.

## Шаг 6. Установите VPN на чистый VPS

В карточке сервера откройте блок **«Установка»**:

- домен: `vps1.mooo.com` (запись A на IP этого VPS, шаг 1; без неё сертификат не выпустится, а на VPS должен быть
  свободен порт 80);
- e-mail для сертификата: ваш адрес;
- выберите Hysteria2 и/или sing-box (VLESS Reality + AnyTLS).

Нажмите «Установить» и следите за журналом. На экране появятся шаги и ошибки, если они будут.
Если на VPS Hysteria2 уже работает: **Импорт профилей с сервера**, затем **Синхронизировать**.

## Шаг 7. Создайте профиль клиента

1. **Профили → создать**: имя `ivan`, срок (например, через месяц), лимит трафика (по желанию).
2. Страница **«Доступ»**: отметьте, к каким серверам у профиля есть доступ.
3. Панель сама отправит изменения на серверы. Откройте профиль: там ссылки `hysteria2://`, `vless://`,
   `anytls://`, QR-код, конфиг для Clash и **ссылка подписки**.

## Шаг 8. Подключите клиента

Передайте человеку ссылку подписки или QR-код. Он вставляет их в приложение:

- Android: v2rayNG, Hiddify, NekoBox, sing-box;
- iOS: Streisand, Shadowrocket, sing-box;
- Windows/macOS/Linux: Hiddify, Clash Verge / mihomo, Nekoray.

(Приложения не входят в проект и могут меняться; подойдёт любое, что понимает нужный протокол.)

Для личного кабинета клиента: **Клиенты → создать** учётку и привяжите к ней профиль, адрес кабинета:
`https://myhelm.mooo.com/<префикс>/`.

## Частые проблемы

| Симптом | Что проверить |
|---|---|
| `nslookup` не показывает IP | подождите 10–30 минут; проверьте тип записи (`A`) и IP |
| certbot ругается на проверку | порт 80 доступен снаружи? проброшен на роутере? совпадает ли IP в DNS |
| Не открывается админка | точный адрес из шага 3; не закрыт ли доступ вашим же IP-фильтром (шаг 3) |
| VPS «не проверяется» | порт SSH, ключ панели в `authorized_keys`, firewall |
| Установка на VPS упала на сертификате | запись A для `vps1…` указывает на этот VPS? порт 80 свободен? |
| Забыли адрес админки | `sudo ROTATE_ADMIN_PATH=1 bash deploy/install-linux.sh` создаст новый |
| Забыли пароль админа | `sudo -u hy2panel /opt/hy2panel/.venv/bin/python /opt/hy2panel/manage.py passwd admin` |

## Безопасность в двух словах

- Делайте резервную копию каталога `data/` (в нём ключи и база) и **никому его не отдавайте**.
- Пароль админа должен быть уникальным, доступ к админке ограничьте по IP.
- Обновление: `cd solahelm && git pull && sudo bash deploy/install-linux.sh` (данные сохраняются).
