# SolaHelm

Панель для самостоятельного размещения: управление серверами **Hysteria2**, а также **VLESS (Reality)** и **AnyTLS**
(через sing-box) на тех же серверах, из одного места. Профили клиентов, ссылки, QR-коды, подписки, мониторинг серверов
и личный кабинет, где клиент видит только свои подключения.

Двуязычный интерфейс (**Русский / English**) с переключателем языка на каждой странице.

> English version: [README.md](README.md)

> **Впервые этим занимаетесь?** Пошаговая инструкция с примерами для начинающих: [GUIDE.ru.md](GUIDE.ru.md).

> **Отказ от ответственности.** Независимый проект сообщества, не связан с Hysteria, sing-box, mihomo и Clash.
> Вы сами отвечаете за соблюдение законов, которые действуют в вашей стране и для ваших серверов.

## Возможности

- **Много VPS из одной панели.** Подключение по SSH (ключ панели, пароль или свой ключ), состояние службы, версия, аптайм,
  CPU / RAM / диск, скорость сети. Старт / стоп / перезапуск, журнал, редактор конфига с бэкапом и автооткатом.
- **Установка одной кнопкой на чистый Debian/Ubuntu VPS:** Hysteria2 (сертификат ACME, сайт-заглушка, `userpass`,
  trafficStats API, ufw) и/или sing-box с VLESS Reality + AnyTLS. Лог установки в реальном времени.
- **Профили:** создание, редактирование, отключение, удаление, срок, лимит трафика, доступ к выбранным серверам
  (матрица «Доступ»). Изменения сами уходят в конфиги серверов с проверкой и откатом.
- **Для клиентов:** ссылки `hysteria2://`, `vless://`, `anytls://`, QR (SVG / PNG), YAML для Hysteria и Clash Meta / mihomo,
  **ссылка подписки** (base64 и Clash) с заголовками трафика и срока.
- **Шаблоны маршрутизации** для Clash/mihomo (DNS, TUN, наборы правил, правила). Загрузите любой готовый конфиг mihomo:
  панель сохранит маршрутизацию и подставит ваши серверы. Два готовых шаблона в комплекте.
- **Кабинет клиента:** отдельные учётные записи (логин + пароль), клиент видит только назначенные ему профили.
- **Мониторинг:** онлайн и трафик по профилям / серверам / дням (Hysteria2), история доступности с графиками,
  устойчивое определение «нет связи» (повторы + N неудач подряд).
- **Незаметность:** случайные префиксы адресов при установке, любой неизвестный путь отвечает обычной 404 в стиле nginx,
  админка на отдельном префиксе (и с отдельным путём cookie).
- **Безопасность:** пароли scrypt, серверные сессии, CSRF, ограничение попыток входа, CSP, журнал действий,
  шифрование SSH-секретов, запоминание ключей хостов.

## Как это работает

```
Браузер ──HTTPS──► nginx ──HTTP──► SolaHelm (127.0.0.1:8088, служба systemd)
  /<префикс>/          кабинет клиентов, /<префикс>/sub/<токен> подписки
  /<префикс>/<админка>/ админка (случайный путь; ограничьте по IP в nginx)
                                      │ SSH
                  ┌───────────────────┼───────────────────┐
                 VPS 1               VPS 2               VPS N
        config.yaml + systemd    hysteria / sing-box    (trafficStats через SSH-туннель)
```

Панель — **источник истины** для пользователей: она переписывает секцию `auth.userpass` в `config.yaml` Hysteria и
inbound'ы `vless-in` / `anytls-in` в sing-box (остальное не трогает), хранит бэкапы с датой и перезапускает службу,
только если что-то изменилось.

## Требования

- Linux-машина, ВМ или WSL2 (Ubuntu / Debian, **включён systemd**) для панели, на ней **nginx** с сайтом по **HTTPS**
  (домен + сертификат, например certbot).
- Python 3.10+ (проверено на 3.12; установщик сам поставит `python3-venv`).
- Один или несколько VPS с Debian/Ubuntu, доступ по SSH под `root` (или пользователь с sudo без пароля).
  Желательна поддерживаемая версия ОС, не снятая с поддержки.

## Нет своего домена? Получите бесплатный (freedns.afraid.org)

Для HTTPS нужно доменное имя. Если своего нет, можно получить бесплатный поддомен на [FreeDNS](https://freedns.afraid.org):

1. Зарегистрируйтесь на <https://freedns.afraid.org/signup/> и подтвердите письмо, которое придёт на почту.
2. Откройте **Subdomains → Add** и выберите:
   - **Type: `A`** (IPv4), для IPv6 — `AAAA`;
   - **Subdomain:** любое свободное имя, например `myhelm`;
   - **Domain:** любой из списка (например `mooo.com`, `us.to` …; список большой, доступность меняется);
   - **Destination:** **публичный IP** машины, на которую указывает имя (см. ниже);
   - введите captcha и нажмите **Save**.
3. Через несколько минут проверьте: `nslookup myhelm.mooo.com` (или `ping myhelm.mooo.com`) должен показать ваш IP.
4. Получившееся имя (`myhelm.mooo.com`) используйте везде, где в этом README написано «ваш домен».

Какой IP куда указывать:

- **Машина с панелью** (nginx + SolaHelm): публичный IP вашего роутера/сервера; пробросьте TCP 80 и 443 с роутера
  на эту машину. Сертификат: `sudo certbot --nginx -d myhelm.mooo.com`.
- **Каждый VPS с Hysteria2** (нужно для сертификата ACME, см. «Подключение VPS»): создайте ещё одну запись `A`
  с IP этого VPS, например `vps1.mooo.com`.
- **Домашний IP меняется?** В FreeDNS откройте **Dynamic DNS**, скопируйте *Direct URL* своей записи и вызывайте
  его периодически, например из cron: `*/10 * * * * curl -s "<ваш Direct URL>" >/dev/null`.

Примечания: у бесплатного аккаунта ограничено число поддоменов; если бесплатный домен уберут из списка или запись долго
не используется, она может перестать работать, поэтому следите за письмами FreeDNS. Собственный домен надёжнее.

## Быстрый старт (Linux / WSL)

```bash
git clone https://github.com/sola21/solahelm.git
cd solahelm
sudo bash deploy/install-linux.sh
```

Установщик спросит домен сайта (тот, что уже обслуживает nginx), публичный префикс для клиентов
(**Enter = случайный**) и логин/пароль администратора. Он создаст **случайный путь админки**, поставит приложение в
`/opt/hy2panel` (venv, `.env`, данные), зарегистрирует службу `hy2panel`, создаст `/etc/nginx/snippets/hy2panel.conf`
и добавит одну строку `include` в конфиг вашего сайта (сначала бэкап; если `nginx -t` не проходит, изменение откатывается).

В конце он напечатает адреса. **Сохраните адрес админки**: он случайный намеренно.

| Что | Адрес |
|---|---|
| Кабинет клиентов | `https://ваш-домен/<префикс>/` |
| Админка | `https://ваш-домен/<префикс>/<случайный-путь>/` |
| Подписка | `https://ваш-домен/<префикс>/sub/<токен>` (с `/clash` — формат Clash) |

Новый случайный адрес админки в любой момент: `sudo ROTATE_ADMIN_PATH=1 bash deploy/install-linux.sh`.

**Ограничьте доступ к админке** (настоятельно рекомендуется): откройте `/etc/nginx/snippets/hy2panel-admin-acl.conf`,
раскомментируйте `allow` / `deny`, затем `sudo nginx -t && sudo systemctl reload nginx`.

Обновление: `git pull` и повторный запуск установщика (код заменяется, `data/` и `.env` сохраняются; перед этим
делается архив прежней установки). Логи: `journalctl -u hy2panel -f`.

Переменные установщика: `SITE_DOMAIN=panel.example.org`, `NGINX_SITE=/etc/nginx/sites-available/mysite`.
Администраторы: `sudo -u hy2panel /opt/hy2panel/.venv/bin/python /opt/hy2panel/manage.py create-admin|passwd|list-admins <логин>`.

Windows без WSL тоже возможен: см. `deploy/install-windows.ps1` и `deploy/nginx-hy2panel.conf`.

### Про скрытие панели

HTTPS уже скрывает путь в URL от тех, кто наблюдает за сетью (видны только домен и IP). Панели на самом деле находят
**сканеры, перебирающие известные пути** (`/admin`, `/panel`, …), и по характерным ответам. Поэтому SolaHelm использует
случайные префиксы, отвечает на неизвестные пути обычной 404 в стиле nginx, никогда не перенаправляет старые пути на
админку, а cookie админской сессии ограничена её путём. Для настоящей защиты добавьте ещё список разрешённых IP в nginx.

## Языки

Интерфейс переключается между русским и английским кнопками **RU | EN** справа вверху (в том числе на страницах входа),
выбор запоминается в cookie. Язык по умолчанию: `HY_DEFAULT_LANG=ru|en|auto` (`auto` — по языку браузера).
Исходный язык — русский, английский — словарь (`app/i18n_en.py`), применяемый к страницам, сообщениям API и журналам установки.
После правок интерфейса проверьте словарь: `python scripts/i18n_extract.py` (покажет непереведённые фразы); то, чего в словаре
нет, остаётся на русском. Добавить ещё один язык — значит добавить ещё один словарь, см. `app/i18n.py`; пул-реквесты приветствуются.

## Подключение VPS

1. **Серверы → Добавить VPS**: адрес, порт SSH, пользователь (`root`).
2. SSH-доступ: добавьте публичный ключ панели (Настройки → «SSH-ключ панели») в `~/.ssh/authorized_keys` на VPS
   или выберите «Пароль» и нажмите «Установить ключ панели».
3. **Проверить**. Если Hysteria2 уже работает: **Импорт профилей с сервера**, затем **Синхронизировать**.
   На чистом VPS используйте блок **«Установка»** (нужен домен с A-записью на VPS и e-mail для ACME).

Hysteria2 занимает UDP 443 и TCP 443/80 (заглушка и ACME), поэтому VLESS и AnyTLS по умолчанию на TCP 8443 / 9443.

## Настройки (`.env`)

Смотрите [`.env.example`](.env.example). Главное:

| Ключ | Значение |
|---|---|
| `HY_BASE_PATH` | публичный префикс (кабинет, подписки); после первой установки случайный |
| `HY_ADMIN_PATH` | подпапка админки внутри него; после первой установки случайная |
| `HY_LEGACY_BASE` | прежние префиксы: подписки работают, остальные пути отвечают 404 |
| `HY_LEGACY_ADMIN_REDIRECT` | `1` = перенаправлять старые пути админки на новый адрес (раскрывает его; по умолчанию выключено) |
| `HY_BRAND` | название продукта в интерфейсе (по умолчанию `SolaHelm`) |
| `HY_DEFAULT_LANG` | `ru`, `en` или `auto` |
| `HY_HOST`, `HY_PORT` | где слушает приложение (по умолчанию `127.0.0.1:8088`) |
| `HY_TRUSTED_PROXIES` | IP вашего reverse-proxy (чтобы доверять `X-Real-IP`) |
| `HY_PUBLIC_URL` | публичный адрес для ссылок подписки (меняется и в «Настройках») |
| `HY_POLL_INTERVAL` | интервал опроса серверов, секунды |

## Безопасность

- У панели есть SSH-ключ, который входит на **все** ваши серверы под root. Берегите машину панели: обновляйте систему,
  наружу открывайте только nginx, ограничьте путь админки по IP, используйте только HTTPS.
- Всё чувствительное лежит в `data/` (`panel.db`, `secret.key`, `panel_ed25519`). **Делайте бэкап и никогда не публикуйте.**
  Без `secret.key` сохранённые SSH-пароли не расшифровать.
- Учёт трафика и «онлайн» есть только у Hysteria2 (её stats API); для VLESS/AnyTLS доступно только состояние службы.
- Если ваш reverse-proxy скрывает реальный IP клиента (NAT / port-proxy), ограничение попыток входа видит один общий адрес.
- Нашли уязвимость? См. [SECURITY.md](SECURITY.md).

## Разработка

```bash
python -m venv .venv && . .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                 # по умолчанию: /hy и /hy/admin
python manage.py create-admin admin
python run.py                                        # http://127.0.0.1:8088/hy/admin/
```

Структура: `app/main.py` (маршруты), `app/hy.py` (конфиг Hysteria / синхронизация / мониторинг), `app/sb.py` (sing-box),
`app/ssh.py`, `app/clients.py` (ссылки, QR, YAML), `app/routing.py` (шаблоны Clash), `app/security.py`,
`app/i18n.py` + `app/i18n_en.py` (локализация), `app/templates`, `app/static`, `deploy/`, `scripts/`.
